Xerox EDMS is a generalized Data Management System for Sigma computers. It provides for the integration of data from
separate aeas of a business into a common database. A database may be subdivided into as many as 64 segments thus 
potentially reducing the computer resources required as only those segments that are to be accessed, need be available
to EDMS. Programs that access the database may be written in COBOL, FORTRAN or METASYMBOL and need only contain a 
description of those portions of the database that they will access.
EDMS consists of a file definition processor, four utility processors and a run-time library. All may be executed 
in either batch or on-line mode. The runtime library may be structured as a shared library. Thus, reducing core 
requirements for application programs.
